# Понятный .NET — работающий канал

Канал: https://t.me/ponyatny_dotnet_diary

Бот управления: https://t.me/ponyatny_dotnet_editor_bot

Первая публикация: https://t.me/ponyatny_dotnet_diary/2

Проект: `C:\Projects\DotNetChannel`, solution `DotNetChannel.sln`.

## Что уже настроено

- Созданы канал и отдельный бот. Боту выдано право публикации сообщений; остальные дополнительные права выключены.
- Управление ботом привязано к владельцу канала. Личный чат с ботом запущен.
- Источник: `NetDeveloperDiary`.
- Модель: `gpt-5.2`. Используется существующий ключ `OPENAI_API_KEY` из настройки LiveCaptioner; ключ в документах не хранится.
- `AutoPublish: true`: подходящие новые материалы публикуются без ручного подтверждения.
- Проверка источника примерно каждые 120 секунд. Максимум 3 попытки генерации за сутки UTC, включая отбор, ошибки и переработки. Во время первоначальной настройки 31 октября использованы все 3 попытки; новые попытки станут доступны после 00:00 UTC.
- Публикуется текст с оформлением кода и ссылками на источник. Изображения, видео и внешние статьи по ссылкам не загружаются.
- Сервис работает в фоне через задачу Windows `DotNetChannel`. Она запускается через 30 секунд после входа пользователя в Windows. Консольное окно не открывается.
- При аварийном завершении задача делает до трёх попыток перезапуска с интервалом в минуту.

Для работы компьютер должен быть включён, не находиться в режиме сна и иметь интернет. Запуск на отдельном сервере в эту настройку не входит. Веб-вкладку и Telegram Desktop можно закрыть: сервис использует API самостоятельно.

## Десктопная админка

На рабочем столе и в папке проекта есть ярлык `DotNetChannel Admin`. Окно позволяет запускать, штатно останавливать и перезапускать сервис, смотреть очередь, тексты постов, ошибки, данные Telegram и журналы. Подробнее: `ADMIN.md`.

## Как управлять

В личном чате с ботом:

- `/status` — состояние очереди и ошибки.
- `/retry ID` — повторить неудачную обработку.
- `/resolve ID published` — подтвердить, что отправка с неопределённым результатом уже состоялась.
- `/resolve ID retry` — после проверки канала разрешить повторную отправку. При AutoPublish=true это означает автоматическую отправку.

Старые черновики первой статьи в личном чате оставлены для истории. Их кнопки устарели и не создают повторных публикаций.

Проверить фоновую задачу в PowerShell:

```powershell
Get-ScheduledTask -TaskName DotNetChannel
```

Остановить или запустить:

```powershell
Stop-ScheduledTask -TaskName DotNetChannel
Start-ScheduledTask -TaskName DotNetChannel
```

Сначала остановите сервис перед ручным запуском, сборкой или изменением настроек.

## Как изменить поведение

Конфигурация: `C:\Projects\DotNetChannel\settings.local.json`.

Для согласования постов перед публикацией установите `AutoPublish: false`. При этом новые черновики будут приходить в личный чат с кнопками. После изменения перезапустите задачу Windows.

Правила переработки: `C:\Projects\DotNetChannel\prompts\rewrite.txt`. Файл читается при каждой генерации. Сейчас он требует простого русского языка, короткого объяснения, сохранения технического смысла и отказа от рекламы/анонсов без содержания.

ИИ может ошибаться. Автоматического запуска произвольного кода из статей и независимого фактчекинга нет. Для первой опубликованной статьи результат примера дополнительно проверен отдельным .NET-тестом.

## Данные и диагностика

- Очередь и история: `data\channel.db`.
- Журналы фонового запуска: `data\logs\service-*.out.log` и `service-*.err.log`.
- Ошибки запускателя: `data\logs\launcher-error.log`, если файл появился.
- Настройки автозапуска: Планировщик заданий Windows → `DotNetChannel`.

Базу не удаляйте при обычном перезапуске: она защищает от повторных публикаций. Для резервной копии остановите задачу и скопируйте папку `data` и локальную конфигурацию. Секретный токен бота хранится в `settings.local.json`, исключённом из Git.

Проверено: сборка без предупреждений и ошибок; 19 автоматических тестов; реальное получение поста, генерация ИИ, доставка черновика, публикация в канале; запуск и перезапуск фоновой задачи Windows.
